# California Class C Knowledge Test — Verified Fact Sheet

Research date: 2026-11-27. All statute text was read on the official California Legislative Information site (leginfo.legislature.ca.gov) in a real browser session; DMV facts were read on dmv.ca.gov / sa.dmv.ca.gov.

**URL convention.** `LEG(n)` = `https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?lawCode=VEH&sectionNum=n` (the exact URL opened). Sections with two versions on file (22352, 27315, 27360.5, 27363) were opened from the "multiple results" picker, which lands on `https://leginfo.legislature.ca.gov/faces/codes_displaySection.xhtml?sectionNum=<n>.&nodeTreePath=<path>&lawCode=VEH`; the exact URLs are given in those rows.

**Wording rule.** Every fact below is a paraphrase of statute text, not handbook text. Rows marked **HANDBOOK GUIDANCE** come from the DMV handbook (CC BY-NC 4.0), not the law. Use them only as concepts and write questions in your own words; never cite them as law.
